# EconoCausal — Tools and Technologies

## Overview

This repository documents the tools and technologies required for the EconoCausal project. The project focuses on analyzing the causal impact of discounts on customer purchasing behavior and exploring effective discount allocation strategies using machine learning and optimization techniques.

## Tools and Technologies

### 1. Python

Python is the primary programming language used for data processing, data analysis, causal inference, and optimization.

### 2. Pandas

Pandas is used to load, clean, manipulate, and analyze customer and discount datasets.

### 3. NumPy

NumPy supports numerical computations, array operations, and mathematical calculations required for data analysis.

### 4. EconML

EconML is used to estimate the causal effects of discounts on customer purchasing behavior using causal machine learning techniques, including Double Machine Learning.

### 5. DoWhy

DoWhy helps define causal assumptions, construct causal models, and analyze causal relationships between discounts and customer purchasing behavior.

### 6. SciPy

SciPy provides scientific computing and optimization methods to explore effective discount allocation under budget constraints.

### 7. React.js

React.js is used to build an interactive web dashboard for presenting project results and analytical insights.

### 8. Plotly

Plotly is used to create interactive charts and visualizations to communicate analytical findings and estimated discount effects.

### 9. Git

Git provides version control for tracking changes and managing project development.

### 10. GitHub

GitHub hosts project documentation and code, tracks contributions, and supports collaboration among team members.

## Project Workflow

1. Understand and prepare customer and discount datasets.
2. Clean and preprocess the data using Pandas and NumPy.
3. Perform exploratory data analysis.
4. Analyze causal relationships using DoWhy and EconML.
5. Estimate the impact of discounts on customer purchasing behavior.
6. Explore discount allocation strategies using SciPy.
7. Present analytical results using Plotly and React.js.
